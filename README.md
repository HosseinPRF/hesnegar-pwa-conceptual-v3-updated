# حس‌نگار (PWA آفلاین)

دو مسیر در یک اپ:

- **ثبت سریع (۶۰–۹۰ ثانیه)**: نام‌گذاری احساس، شدت، بدن، تریگر، جملهٔ ذهن، انتخاب یک تکنیک، اقدام کوچک.
- **تحلیل عمیق (۷–۱۲ دقیقه)**: واقعیت/داستان، احساس‌های زیرین، نیازهای تئوری انتخاب، گفتگوی درونی (TA)، ریشه/آشنایی، انتخاب تکنیک، پلان، ارزیابی.

ویژگی‌های مفهومی اضافه‌شده:

- **هدف جلسه (Session Goal)** برای اینکه خروجیِ هر ثبت شفاف باشد.
- **فلوهای فوری ۲–۴ دقیقه** (پانیک/خشم/نشخوار/شرم/لحظه خوب) برای وقتی که «تصمیم‌گیری بین مسیرها» خودش سخت است.
- **پل Insight → Action**: وضعیت اقدام (انجام شد/برنامه‌ریزی/انجام نشد + مانع) تا خروجی صرفاً نوشته نباشد.
- **اثر تکنیک‌ها**: ثبت «قبل/بعد» و مدت زمان، و نمایش میانگین کاهش شدت در تاریخچه.
- **کمک‌کردن/سختی تکنیک**: ثبت ۰–۵ تا مشخص شود «کدام تکنیک با کمترین سختی، بیشترین اثر را برای شما دارد».
- **Needs → Scripts**: برای هر نیاز (تئوری انتخاب) پیشنهاد «درخواست سالم» و «مرز سالم».
- **راهبردِ تامین نیاز**: تشخیص الگوی قدیمی (اجتناب/کنترل/…)، و ساخت یک جایگزین سالم‌تر.
- **دام‌های شناختی + فکر متعادل‌تر** (CBT): انتخاب ۱–۲ دام و نوشتن جایگزین واقع‌بینانه.
- **آسیب‌پذیری روز (HALT/PLEASE)**: کم‌خوابی/گرسنگی/تنهایی/… برای فهم اینکه چرا امروز حساس‌ترم.
- **یادآوری هویت**: پیوند دادن هر ثبت به «اصول زندگی / نقاط بهبود / موهبت‌ها» داخل خود مسیر ثبت.
- **Safety Layer**: اگر شدت بالا یا فکر آسیب فعال باشد، پیام ایمنی نمایش داده می‌شود.
- **هدف هفتگی**: یک هدف کم‌فشار بر اساس تعداد تمرین‌های انجام‌شده.

همه داده‌ها فقط داخل **localStorage** دستگاه شما ذخیره می‌شود.

## اجرا

### گزینه ۱: باز کردن مستقیم
فایل `index.html` را باز کنید.

### گزینه ۲: نصب PWA
بهترین تجربه وقتی است که با یک سرور محلی اجرا کنید تا Service Worker فعال شود:

```bash
# با npm
npx serve .
```

سپس در مرورگر (Chrome/Edge) گزینه **Install** را بزنید.

## خروجی/ورودی
- از دکمه **خروجی JSON** برای دانلود رکوردها + هدف هفتگی + لیست‌ها (دستاوردها/اصول/بهبودها) استفاده کنید.
- از **ورود JSON** برای وارد کردن فایل خروجی قبلی.
